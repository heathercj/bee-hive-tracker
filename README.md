# Bee Hive Tracker

A small learning project: a honey bee hive & inspection tracker, built to practice
software development alongside application security tooling (SAST, SCA, DAST).

## What it does

- Track hives: name/number, location, box configuration (deep/medium frames + date added), feeding status
- Log inspections: date, queen spotted, observations (eggs, brood, capped brood, drone cells, honey storage),
  pest/disease notes, action taken
- View inspection history per hive
- See which hives are overdue for inspection

## Tech stack

- Node.js + Express (backend/server)
- SQLite (local database)
- Plain HTML/CSS/JavaScript (frontend, no framework)
